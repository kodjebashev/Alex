# Александра 👑 20

Сайт-изненада за 20-ия рожден ден. React + Vite, без допълнителни библиотеки.

## Стартиране
```
npm install
npm run dev
```

## Къде се попълва съдържанието
| Какво | Къде |
|---|---|
| 20-те причини (страница „20“) | `src/reasons.js` |
| Тайна изненада, „Месец по месец“, Оскари, 20 пожелания (балони), реч, съобщение под тортата | `src/content.js` |
| Линк към видеото | `src/pages/Video.jsx` → `VIDEO_URL` |
| Музика | файл в `public/` (напр. `public/music.mp3`) и `MUSIC_URL` в `src/App.jsx` |
| Снимки | в `public/`, пътят се пише в `content.js` (напр. `'/snimka1.jpg'`) |

## Страници (ред в `src/routes.js`)
Месеци (начална, с плика) → 20 → Балони → Оскари → Торта → Видео.
Тайната изненада се отваря с 5 бързи натискания на короната.

## Пускане онлайн
`npm run build`, после папката `dist/` се качва във Vercel, Netlify или GitHub Pages.
Микрофонът (духането на свещите) работи само през HTTPS.
